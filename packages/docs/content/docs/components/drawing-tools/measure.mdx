| Tool               | Type                | Shows                                      |
| ------------------ | ------------------- | ------------------------------------------ |
| Date range         | `dateRange`         | Number of bars and the duration            |
| Value range        | `priceRange`        | Change between two values and the % change |
| Date & value range | `dateAndPriceRange` | Both                                       |

Each measurement takes two points and is colored by direction (up / down). They are regular drawings: keep them on
the chart, or remove them when done. The type names come from the y value being called `price` in drawing points.
