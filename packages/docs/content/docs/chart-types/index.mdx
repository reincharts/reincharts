All chart types are **series** components from `@reincharts/series`. They share the same props for naming, scales and
visibility, read values with accessors, take their colors from the theme, and plug into autoscale, legends, tooltips
and the crosshair automatically. Combine as many as you like in a pane.

## Accessors and generics

Every value prop accepts a field name (`y="revenue"`) or a function (`y={(d) => d.revenue / 1000}`). TypeScript cannot
infer the datum type from a string, so pass it explicitly when you use per-datum functions:

```tsx
<ScatterSeries<Point> y="y" fill={(d) => (d.y < 0 ? "#ef4444" : "#3b82f6")} />
```

## Common props

Every series takes `name` (legend and tooltip label), `scale` (the y scale id, default `"right"`), `visible` and
`zIndex`. The full list is in the [`SeriesProps` reference](/api/series/types#seriesprops).
