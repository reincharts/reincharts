| Tool        | Type         | Points | Notes                                                                              |
| ----------- | ------------ | ------ | ---------------------------------------------------------------------------------- |
| Price label | `priceLabel` | 1      | Shows the price at the point, or `style.text`                                      |
| Price line  | `priceLine`  | 1      | Horizontal line with a title, an axis label and a close button; triggers `onCross` |

Price lines are draggable, so they work well for orders, targets, stops and
[alerts](/docs/components/drawing-tools/alerts). For a fixed line that users can't move, use
[`<PriceLine>`](/docs/components/price-lines).
