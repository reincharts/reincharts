## Usage

```tsx
<BaselineSeries base={55} />
```

Values above `base` use `topColor` (theme `up`), values below use `bottomColor` (theme `down`). Without `base` the
series uses the price at the vertical middle of the pane, so the split follows
panning and zooming.
