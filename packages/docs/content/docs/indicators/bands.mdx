## Usage

```tsx
<BollingerBands period={20} multiplier={2} />
<Indicator definition={indicators.keltner} />
<Indicator definition={indicators.donchian} inputs={{ period: 55 }} />
<Indicator definition={indicators.envelope} />
```

| Id          | Indicator                               | Calculator  |
| ----------- | --------------------------------------- | ----------- |
| `bollinger` | Moving average ± standard deviations    | `bollinger` |
| `keltner`   | Moving average ± ATR multiples          | `keltner`   |
| `donchian`  | Highest high / lowest low over a period | `donchian`  |
| `envelope`  | Moving average ± a percentage           | `envelope`  |

Every band calculator returns `{ upper, middle, lower }`. The band between `upper` and `lower` is filled; hide the
fill with `showFills={false}`.
