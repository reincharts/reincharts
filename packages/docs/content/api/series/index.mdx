## Components

| Name | Description |
| --- | --- |
| [AreaSeries](/api/series/area-series) | A line with a filled area below it (gradient by default). |
| [BarSeries](/api/series/bar-series) | Vertical bars from a base value (histograms, column charts, MACD histograms...). |
| [BaselineSeries](/api/series/baseline-series) | A line whose fill and color switch between two colors above / below a base value. |
| [BubbleSeries](/api/series/bubble-series) | Scatter plot whose marker area is proportional to a third value (`r`). |
| [CandlestickSeries](/api/series/candlestick-series) | Candlesticks (also hollow candles and Heikin Ashi data). |
| [ColumnsSeries](/api/series/columns-series) | "Columns" chart type: a column per bar up to the close, colored by the change from the previous close. |
| [ErrorBarSeries](/api/series/error-bar-series) | Vertical error bars (whiskers) around a value. |
| [GroupedBarSeries](/api/series/grouped-bar-series) | Several bars side by side per x slot (category or bar). |
| [GroupedHorizontalBarSeries](/api/series/grouped-horizontal-bar-series) | Grouped horizontal bars: `ys` holds one accessor per bar of a category (see `HorizontalBarSeries` for the setup). |
| [HLCAreaSeries](/api/series/hlc-area-series) | HLC area: a high–low band split by the close line into an upper and a lower fill. |
| [HorizontalBarSeries](/api/series/horizontal-bar-series) | Horizontal bars. |
| [KagiSeries](/api/series/kagi-series) | Kagi chart: thick yang and thin yin lines that switch when a line breaks the previous peak / trough. |
| [LineBreakSeries](/api/series/line-break-series) | Line break (three line break) boxes: one box per datum of the line break transform. |
| [LineSeries](/api/series/line-series) | A line through one value per bar (also step lines and smooth monotone splines). |
| [OHLCSeries](/api/series/ohlc-series) | OHLC bars: a vertical high–low line with an open tick on the left and a close tick on the right (or HLC bars). |
| [OverlayBarSeries](/api/series/overlay-bar-series) | Several bars drawn over each other from the same base, largest at the back. |
| [PointAndFigureSeries](/api/series/point-and-figure-series) | Point & figure chart: columns of X (rising) and O (falling) boxes. |
| [RenkoSeries](/api/series/renko-series) | Renko bricks: fixed-size boxes stacked diagonally, one per datum of the renko transform. |
| [ScatterSeries](/api/series/scatter-series) | Markers at (x, y) per datum: scatter plots (works with unsorted data in `xMode="linear"`), dot plots and indicator dots such as Parabolic SAR. |
| [StackedAreaSeries](/api/series/stacked-area-series) | Areas stacked on top of each other (or normalised to 100% with `offset="percent"`). |
| [StackedBarSeries](/api/series/stacked-bar-series) | Bars stacked on top of each other per x slot (negative values stack downwards). |
| [StackedHorizontalBarSeries](/api/series/stacked-horizontal-bar-series) | Stacked horizontal bars: `ys` holds one accessor per segment (see `HorizontalBarSeries` for the setup). |
| [StraightLine](/api/series/straight-line) | A horizontal or vertical reference line across the pane (thresholds, targets, overbought / oversold levels). |
| [VolumeCandlesSeries](/api/series/volume-candles-series) | Candles whose color intensity and / or body width reflect the bar's volume relative to the visible bars. |
| [VolumeProfileSeries](/api/series/volume-profile-series) | Volume profile: a horizontal histogram of traded volume by price over the visible bars (or per session), split up / down. |
| [VolumeSeries](/api/series/volume-series) | Volume histogram colored by candle direction. |

| [stack](/api/series/functions#stack) | Stacks several values per datum. |

| [toArray](/api/series/functions#toarray) | Normalizes `SeriesValues` (one value, several or none) to an array. |
| [traceArea](/api/series/functions#tracearea) | Traces closed area shapes between a top line and a bottom line (or a constant bottom y). |
| [traceMarker](/api/series/functions#tracemarker) | Adds a closed marker sub-path centred on (x, y) to a path or context. |
| [tracePath](/api/series/functions#tracepath) | Traces a path through points into `ctx` (shared by line and area series). |
| [verticalGradient](/api/series/functions#verticalgradient) | A vertical linear gradient between two colors over [y0, y1]. |
| [volumeProfile](/api/series/functions#volumeprofile) | Buckets the volume of bars start..end into `bins` price rows. |
