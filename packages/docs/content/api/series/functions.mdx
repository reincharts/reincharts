## drawOhlcColumns

Draws OHLC data with several bars per pixel: one aggregated bar per pixel column (first open, max high,
min low, last close) as a 1px line, merging pre-aggregated blocks when a whole block shares a pixel.
The picture matches drawing every bar; the cost is proportional to the chart width.

```ts
function drawOhlcColumns<T>(
    ctx: CanvasRenderingContext2D,
    { data, start, end, x, y, barSpacing }: DrawScope<T>,
    open: Value<T>,
    high: Value<T>,
    low: Value<T>,
    close: Value<T>,
    color: (up: boolean, d: T, i: number) => string,
): void
```

## getLod

The cached LOD index of `data` for a low / high accessor pair (the same function twice for a single value).
Returns undefined for short series. Keyed by the data array and the accessor, so it is rebuilt only when they change.

```ts
function getLod<T>(data: readonly T[], low: Accessor<T>, high?: Accessor<T>): Lod | undefined
```


## groupLayout

Splits a slot of `slot` pixels into `count` side-by-side bars separated by `gap` pixels.
Returns the integer width of each bar and the offset of bar k's centre from the slot centre.

```ts
function groupLayout(
    slot: number,
    count: number,
    gap?: number,
): { width: number; offsets: number[]; }
```

## stack

Stacks several values per datum. Returns one array per key with `[y0, y1]` for each datum
(`undefined` where the value is missing). Positive values stack upwards from 0 and negative
values downwards from 0 (diverging), so mixed-sign stacks never overlap.

```ts
function stack<T>(
    data: readonly T[],
    keys: readonly Accessor<T, number | undefined>[],
    { offset }?: StackOptions,
): (StackedValue | undefined)[][]
```


## stackAt

Stacks the values of one datum, calling `emit(keyIndex, [y0, y1])` per key (used per frame by series).

```ts
    fns: readonly ((d: T, i: number) => number | undefined)[],
    offset: StackOptions["offset"],

```

## volumeProfile

```ts
    isUp: (d: T, i: number) => boolean,
```
