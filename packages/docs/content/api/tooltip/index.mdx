## Components

| Name | Description |
| --- | --- |
| [Legend](/api/tooltip/legend) | Pane legend in the top-left corner of a pane: name and values of every series at the crosshair (or the last bar). |
| [Tooltip](/api/tooltip/tooltip) | Floating tooltip that follows the pointer: a card with the hovered x and the values of the pane's series. |
| [TooltipCard](/api/tooltip/tooltip-card) | The default tooltip card (exported to build custom tooltips with the same look). |
