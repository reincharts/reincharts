## Hooks

| Name | Description |
| --- | --- |
| [useBarReplay](/api/datafeed/use-bar-replay) | Bar replay: hides bars after a start index and reveals them one by one (play, pause, step, step back, speed). |
| [useDatafeed](/api/datafeed/use-datafeed) | Connects a `Datafeed` to a chart: loads history, merges realtime bars, paginates backwards, resets on symbol / resolution change and ignores stale responses. |
