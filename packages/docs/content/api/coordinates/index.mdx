## Components

| Name | Description |
| --- | --- |
| [Crosshair](/api/coordinates/crosshair) | Crosshair: dashed lines across all panes at the hovered bar and in the hovered pane at the pointer (or the magnet value), with labels on the time axis and on every price axis of the pane. |
| [CurrentCoordinate](/api/coordinates/current-coordinate) | A dot on a series at the hovered bar (follows the crosshair, also when synced from another chart). |
| [EdgeIndicator](/api/coordinates/edge-indicator) | A price axis label (and optional line) for the first or last visible value of any accessor. |
| [LastValueLabel](/api/coordinates/last-value-label) | Colored labels with the last value of each series of the pane on the price axis. |
| [LastValueLine](/api/coordinates/last-value-line) | `LastValueLabel` with a dotted line across the plot at each last value. |
| [PriceLine](/api/coordinates/price-line) | A horizontal price line with an axis label and optional title. |
