## crosshairPoint

Computes where the crosshair lines go: snapped to the bar center in index mode
(including empty future slots for time data), free in linear mode, magnet-snapped vertically.

## drawValueMarkers

Draws price lines / axis labels for one price scale of a pane (ctx at the pane plot origin, unclipped).

```ts
function drawValueMarkers(
    ctx: CanvasRenderingContext2D,
    scope: DrawScope,
    scaleId: string,

```
