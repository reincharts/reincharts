## HeikinAshiBar

A source bar with its OHLC replaced by Heikin Ashi values (every other field, e.g. date / volume, is kept).

```ts
type HeikinAshiBar<T> = Omit<T, "open" | "high" | "low" | "close"> & {
    open: number;
    high: number;
    low: number;
    close: number;
};
```
